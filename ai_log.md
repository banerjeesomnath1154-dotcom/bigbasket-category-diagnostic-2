## AI Prompt #1: SQL Target Variance & Category Diagnostic Query Development

### **1. Prompt Structure (RCTCF Framework)**

* **Role:** Senior Analytics Engineer & Data Architect.
* **Context:** I am constructing a SQL reporting script (`03_reporting.sql`) against an SQLite database (`bigbasket_capstone.db`) for BigBasket category managers. The database contains an `orders` table (with columns `order_id`, `product_id`, `amount_inr`, `status`, `order_date`), a `products` table (with `product_id`, `product_name`, `category`), and a `category_targets` table (with `category`, `target_revenue_inr`).
* **Task:** Draft a SQL query that joins total Delivered order revenue per category to `category_targets`, calculates the absolute variance (`target_revenue_inr - total_revenue`), calculates the percentage variance (`((total_revenue - target_revenue_inr) * 100.0) / target_revenue_inr`), and assigns a `target_status` tag:
  * `'Above Target'` if `total_revenue >= target_revenue_inr`
  * `'Below Target - Watch'` if percentage shortfall is within 15% (i.e. `percentage_variance >= -15.0`)
  * `'Below Target - Critical'` otherwise.
* **Constraints:** Must handle SQLite integer division correctly (multiplying by `100.0` or casting to floating point so numbers are not truncated to zero). Filter strictly for `o.status = 'Delivered'`. Order results by `total_revenue DESC`.
* **Format:** Return executable SQLite code wrapped in Markdown SQL code blocks with concise inline commentary explaining the SQLite division logic.

---

### **2. Concrete Verification Step Performed**

To verify the query generated by the AI:
1. **Execution Test:** Executed the query directly against `bigbasket_capstone.db` using Python's `sqlite3` and `pandas` library.
2. **Formula & Calculation Audit:** Manually spot-checked the output row for **Fruits & Vegetables**:
   * Total Delivered Revenue: `10,080` INR
   * Target Revenue: `15,000` INR
   * Expected Variance: `15,000 - 10,080 = 4,920` INR
   * Expected Percentage Variance: `((10,080 - 15,000) * 100.0) / 15,000 = -32.80%`
   * Expected Target Status: `'Below Target - Critical'` (since `-32.80% < -15.0%`).
3. **Result:** Verified that the query returned `10080`, `4920`, `-32.8`, and `'Below Target - Critical'` matching the exact hand calculation.
